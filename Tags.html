.Algumas Tags e suas funções

Todas as tags começam com um sinal de menor e terminam com sinal de maior(< >).

h1 : é uma tag que serve para escrever um titulo ou subtitulo. E começam de 1 à 6.

P: Serva para escrever paragráfos ou mudar de linhas.

A: essa tag serve para criar âncoras ou links que servem de atalhos no site.

UL: é uma tag que serve para organizar os caracteres ou textos no site.

LI: serve para organizar os elementos em alinhas ou ordem crescente.

main: essa é uma tag de introdução para criação de telas de login. Funciona como a tag header.

Nav: é uma tag de navegação. É colocada no principio de um site ou na pagina inicial, nela contêm as tags(a, ul, e li).

header: é uma tag de introdução de elementos ou tags, funciona como uma classe.

head: essa tag tem como o nome de cabeçalho da página. É onde são colocados as configurações, mas não se vê no site.

body: é o corpo do site ou o quadro onde aparecem os textos, images, paragráfos e videos que colocamos no documento.

footer: essa é uma das tags muito importantes para organozar as frazes: -Criado por (nome do autor). -politica de privacidade | contacto e etc.

Input: é uma tag que serve para criar fórmularios. Também ajuda na criação de telas de login e campos de busca.

div: essa tag serve para duvidir ou fazer uma duvisão. Também para chamar nomes de classes e etc.

Duas tags essencias para dar mas sentido num site.

São tags que melhoram e dá um bom visual no site. É provável queum site sem video e imagem claro que fica mal estruturado né?

IMG é uma tag que serve para colocar uma imagem no nosso site ou código html com parâmetro (src).

Video serve para colocar vídeo no nosso site ou código html, Coloca-se um vídeo com o caminho (Suorce) e com parâmetro (src).
