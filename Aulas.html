Aula 2. Tags e suas funções

Tags são os tijolos do HTML.Tudo que você vê num site é feito com tags. Também é o comando entre< > que diz pro navegador"Ó, aqui começa um paragrafo" ou isso"aqui é uma imagem".

Tags é tudo o que aparece em uma estrutura html. Veja a imagem anterior!

Todas tags começam com sinal de menor e terminan com sinal de maior. Essas tags são varias e têm suas funcões.

O quê aprendemos?

HTML é a estrutura do site.

CSS é a estilização. Como: mudança de cores, centralização de caracteres, mudar tamanho das letras etc.

Java script é o cerêbro de um site, faz ele funcionar.
