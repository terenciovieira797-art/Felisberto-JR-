HTML+CSS+JS

HTML, CSS e JS são linguagens para desenvolver e criar sites.

(Esqueleto) HTML Hipertext Marckup language. É uma linguagem de marcação que extrutura o conteúdo da pagina.

(A roupa) CSS casting stylesheets. É uma linguagem que estiliza a pagina.

CSS diz"Como"as coisas aparecem. Ele pinta,posiciona,anima,define cor, tamanho, fonte,se fica do lado ou embaixo.

(O cerebro) Javascript JS diz "O que acontece" quando o usuário mexe.

Ele faz o site reagir: Clica no menu e troca o jogo, valida formulário, busca dados, anima coisa.

Essas são linguagens essências para o desenvolvimento de qualquer projecto html.

Dicas para ser um gênio da programação web

Gênio não nasce, se fabrica. E não é decorando tudo. É treinando o cérebro todos os dias.

Aqui vão 5 dicas que realmente funcionam, sem papo furado:

*1. Domina o básico até virar reflexo*

Gênio parece que tira solução do nada, mas na real ele só domina o básico tão bem que sobra cérebro pra parte difícil.

.Como aplicar na programação?

Faz o layout com CSS Grid 10x até você escrever `display: grid` sem pensar. Quando o básico vira automático, você usa a cabeça pra lógica, não pra lembrar sintaxe.

*Regra*:

*1Se você ainda googla "como centraliza div", você não dominou o básico. Treina mais.

*2. Treina desconforto diário*

Cérebro cresce igual músculo: só com carga. Se tá fácil, não tá aprendendo.

*Como aplicar*: Todo dia pega 1 problema que você não faz ideia como resolver e quebra a cabeça por 30min antes de ver resposta. Travou no JS? Ótimo. Fica travado. A resposta tá no F12 e no `console.log()`, não no ChatGPT.

*Regra*: 30min de soco na parede > 3h copiando código pronto.

*3. Ensina pra aprender 2x mais*

Explicar é o teste final. Se você não consegue explicar `forEach` pro teu primo de 12 anos, você não entendeu ainda.

*Como aplicar*

:

1. Grava vídeo de 5min explicando como fez.

2. Escreve post no LinkedIn: "Hoje aprendi a diferença de `let` vs `const`"

3. Corrige código de iniciante em grupo de WhatsApp

Quando você ensina, o cérebro reorganiza a info e cola pra sempre.

*4. Rouba igual artista*

Gênio não inventa do zero. Ele copia dos melhores, mistura tudo, e sai algo novo.

*Como aplicar*:

1. Abre 3 sites que você acha foda: Apple, Tupuca, Awwwards.

2. Rouba 1 detalhe de cada: a animação de um, as cores de outro, o layout de outro

3. Junta no teu site que queres criar.

Picasso já falava: "Bons artistas copiam, grandes artistas roubam".

*5. Obsessão + Tédio = Gênio*

Gênio é só um cara obcecado que aguentou o tédio de repetir a mesma coisa 1000x.

*Como aplicar*:

1. *Obsessão*: Escolhe 1 coisa pra ser top 1% No meu país. Ex: "Quero ser o cara do CSS Grid no meu local ou na sociedade".

2. *Tédio*: Faz 1h de código todo dia mesmo no dia que não tá afim. Sem música, sem YouTube. Só você e o VS Code.

Em 6 meses você olha pra trás e os outros vão falar "você é gênio". Na real você só não parou.

*Bônus - O anti-dica:*

Para de tentar ser gênio em tudo. Escolhe HTML/CSS/JS e ignora Python, Java, PHP por enquanto. Foco estreito cria gênio. Foco espalhado cria mediano que sabe meio de tudo.

*Teste pra hoje*: Cria e seja um bom programador web.
